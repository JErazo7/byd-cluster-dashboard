# Theme image assets

All images in this directory are owned by the project, except the optional pickup cut-out
described below. The photographic scenes (`bg*.jpg`) are original artwork.

`truck.png` — the 3/4 front pickup used in the centre of the skin — is **not included**
because its rights are not cleared for redistribution. The skin works without it: the
`<image>` element simply draws nothing and the speed, rings and cards stay in place.

To use the full theme, drop your own cut-out here with this exact name:

| File | Content | Reference size |
|---|---|---|
| `truck.png` | pickup with alpha, front 3/4 view | ~800×406 (the skin scales it) |

Use an image you have the right to redistribute. A photo that is merely visible on a
manufacturer site or social media is not licensed for reuse, and attribution alone does
not grant that right.
